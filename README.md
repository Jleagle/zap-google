## Installation

```bash
go get github.com/Jleagle/zap-google
```

## Usage

```go
package main

import (
	"context"

	"cloud.google.com/go/logging"
	"go.uber.org/zap"
)

func main() {
	ctx := context.Background()
	client, err := logging.NewClient(ctx, "your-project-id")
	if err != nil {
		panic(err)
	}
	defer client.Close()

	// Create a single GCP logger stream
	gcpLogger := client.Logger("my-log-stream")

	core := zapgoogle.NewCore(ctx, gcpLogger, false)

	logger := zap.New(core)
	defer logger.Sync()

	logger.Info("hello world", zap.String("foo", "bar"))
}

```

## Google Cloud Error Reporting

This package is optimized for Google Cloud Error Reporting out-of-the-box:

- Logs with `Error`, `DPanic`, `Panic`, or `Fatal` level automatically include the `@type` identifier `type.googleapis.com/google.devtools.clouderrorreporting.v1beta1.ReportedErrorEvent`.
- Source location (file, line, function) is automatically extracted and natively populated on the Cloud Logging entry.
- Stack traces generated by zap (via `zap.AddStacktrace`) are mapped to the `stack_trace` key.

### Grouping and Service Context

For optimal error grouping in the Error Reporting dashboard, it is highly recommended to supply a `serviceContext` with your logger:

```go
logger = logger.With(
    zap.Dict("serviceContext",
        zap.String("service", "my-app"),
        zap.String("version", "1.0.0"),
    ),
)
```
